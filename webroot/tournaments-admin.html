Admin Features

Team Management
  • Add and edit team information
  • Set captain Discord tags
  • Set captain game IDs
  • Randomize team bracket positions
Bracket Control
  • Support for 4, 8, or 16 team brackets
  • Advance winners to next rounds
  • Track match progression
  • Reset bracket if needed
Tournament Details
  • Edit tournament title
  • Update tournament description
  • Set tournament dates
  • All changes reflected immediately on public page
Data Management
  • Auto-save progress
  • Manual save all changes
  • Data persisted locally
  • Reset option available
Important Notes
  • Password: The default admin password is "svgeadmin2025"
  • Session: Your admin session lasts for 2 hours before requiring re-authentication
  • Data Storage: All tournament data is stored locally in the browser
  • Public View: Changes are immediately visible on the public tournament page
  • Save Often: Remember to click "Save All Changes" after making edits
